# LeadynDSH 品牌与“更多”菜单修改指南

## Summary

本指南说明如何替换客户端与桌面端的 LeadynDSH 品牌标记和产品名称，以及如何扩展侧边栏账号启动器的“更多”菜单。客户端品牌 SVG 与 Windows 图标源文件分别维护，修改时需要同步更新。菜单条目使用双语文案，并由账号组件处理选择动作。

## 替换应用品牌

LeadynDSH 的品牌分布在客户端品牌组件、桌面壳文案和安装产物配置中。修改名称或图标时，先确定目标显示位置，再更新对应资源；只替换一个 SVG 文件不会自动更新所有界面。

| 显示位置 | 修改位置 | 说明 |
| --- | --- | --- |
| 客户端品牌图标和名称 | [`Brand.tsx`](../packages/client/ui-brand-official/src/client/Brand.tsx) | `OfficialBrandMark` 使用客户端图标组件；`OfficialBrandName` 提供名称。 |
| 客户端品牌图形 | [`LeadynLogo.tsx`](../packages/client/ui-primitives/src/LeadynLogo.tsx) | 图形以内联 SVG 保存，不会从桌面图标源文件读取。 |
| 桌面欢迎页、原生菜单和对话框 | [`locale.ts`](../apps/desktop/src/locale.ts)、[`main.ts`](../apps/desktop/src/main.ts) | 英文和中文文案分别维护；About 面板名称由主进程设置。 |
| 安装后产品名 | [`electron-builder-config.mjs`](../apps/desktop/scripts/electron-builder-config.mjs)、[`strings.nsh`](../apps/desktop/installer/strings.nsh) | `productName` 用于安装产品名和可执行文件名；安装器文案也可能显示产品名。 |
| Windows 应用图标 | [`logo.svg`](./logo.svg) | 这是 Windows 图标生成器读取的 SVG 源文件。 |
| Windows 系统托盘图标 | [`render-tray-icon.ts`](../apps/desktop/scripts/render-tray-icon.ts)、[`logo.svg`](./logo.svg) | 托盘图标与 Windows 应用图标使用同一品牌源；重新生成 `tray-windows.ico` 后会打包为 `tray.ico`。 |
| macOS 应用图标 | [`icon-macos.png`](../apps/desktop/resources/icon-macos.png) | 独立于 Windows 生成器；替换 macOS 图标时需要单独更新。 |

替换客户端标记时，同步调整 `LeadynLogo.tsx` 中的 SVG 图形和 `Brand.tsx` 中显示的名称。客户端标记和 Windows 应用图标使用独立资源，因此分别检查客户端界面和 Windows 安装产物。

Windows 图标生成器不会更新 macOS 图标。若本次品牌替换也涵盖 macOS Dock 图标，单独替换 `icon-macos.png` 并检查 macOS 安装产物。

替换桌面产品名时，更新英文及中文的桌面文案，并同步更新 Electron About 面板的 `applicationName` 和 electron-builder 的 `productName`。如果安装器文案包含产品名，也要更新 `strings.nsh`。

Windows 应用图标由 `logo.svg` 生成。仓库脚本会裁去透明边距，并生成 [`icon-windows.png`](../apps/desktop/resources/icon-windows.png) 和 [`icon-windows.ico`](../apps/desktop/resources/icon-windows.ico)：

```powershell
pnpm --filter @deepseek-ai/dsh-desktop render:windows-app-icon
```

Windows 系统托盘图标也由 `logo.svg` 生成。替换品牌 SVG 后，运行托盘图标生成器以更新 [`tray-windows.ico`](../apps/desktop/resources/tray-windows.ico)：

```powershell
pnpm --filter @deepseek-ai/dsh-desktop render:tray-icon
```

桌面包名、`appId`、Electron `app.name` 和 `deepseek-harness-*` 发布产物名不是显示品牌的同义项。不要为更改显示名称而修改这些标识；Electron `app.name` 还决定默认用户数据目录。

## 修改“更多”菜单

本文的“更多”菜单指侧边栏账号启动器 [`AccountMenu.tsx`](../packages/client/ui-settings-account/src/client/AccountMenu.tsx)：未登录且侧栏展开时，触发按钮显示“更多”；打开后当前只显示“设置”。账号资料区中 [`AccountSection.tsx`](../packages/client/ui-settings-account/src/client/AccountSection.tsx) 的“更多”是用量和充值链接的分组标题，不是这个菜单。

在 `AccountMenu.tsx` 的 `Menu` 调用中修改 `items` 数组。每个可选条目需要稳定且唯一的 `id` 和通过 `t(...)` 取得的本地化 `label`；可按需要提供图标、快捷键、禁用状态或子菜单。`Menu` 的 `onSelect` 回调收到被选条目的 `id`，因此加入新条目时也要按 `id` 分派对应动作，不能让所有条目继续无条件调用 `openSettings()`。

在同一功能的 [`locales.ts`](../packages/client/ui-settings-account/src/client/locales.ts) 中加入英文和中文文案，并在账号组件已有的属性或注入服务中接入新动作。保留菜单关闭和焦点返回触发按钮的行为。

同步更新 [`account.client.spec.tsx`](../packages/client/ui-settings-account/tests/account.client.spec.tsx)：覆盖中英文、已登录和未登录状态下的菜单条目及各条目动作；菜单内容变化时，更新 `tests/expected/menu*.txt` 对应快照。

## 验证修改

替换 Windows 图标后，运行图标生成器，并检查生成的 PNG、ICO 资源。修改账号菜单后，运行账号菜单测试，确认双语条目、选择动作和菜单关闭行为：

```powershell
pnpm --filter @deepseek-ai/dsh-desktop render:windows-app-icon
pnpm --filter @deepseek-ai/dsh-desktop render:tray-icon
pnpm test -- apps\desktop\tests\tray-icon.spec.ts apps\desktop\tests\installer-packaging.spec.ts packages\client\ui-settings-account\tests\account.client.spec.tsx
```
